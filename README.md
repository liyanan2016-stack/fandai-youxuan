# 反代优选

Cloudflare 反代 IP 优选工具。Android + Windows / Linux 桌面版。

从已验证的反代节点列表里挑出**在你当前网络下最快**的那一个，支持按地区和端口筛选。

> 本仓库只发布成品，不公开源码。

## ⚠️ 使用限制

**仅供中国大陆网络环境使用。** 每次扫描和更新数据前都会检查出口地区，
不在范围内会说明原因并拒绝使用。

如果你在境内却被拒绝，通常是开着**代理或 VPN**，关掉再重试即可。

**检查失败（网络不通、被拦截、超时）时也会拒绝**，并提示你检查网络。
这是有意为之：如果检查失败就放行，那断网本身就成了绕过限制的办法。
被拦下时点「重新检查网络」可以原地重试，不用重启程序。

## 这个工具做什么

**做**：对候选节点测 RTT 和真实下载速度，输出一个最快的 `IP:端口`。

**不做**：任何形式的代理、加速、翻墙。它只输出一个地址，拿去做什么由你自己决定。

优选结果与网络环境强相关。换 WiFi、换运营商、换城市，甚至只是过几小时，
最快的节点都可能变——这是「用时再扫」的工具，不是「扫一次用一年」。

## 首次使用

**1. 输入密码解锁。** 界面会给提示，答对即可，只需一次。

**2. 点「更新数据」。** 不下载节点列表就没有候选，扫描无法开始。

**3. 设置筛选条件（可选）。** 可以只扫指定地区、指定端口。
筛选范围越小扫得越快，但太窄可能一个可用的都找不到。

**4. 填期望带宽。** 不知道填多少就先填 1，看实测多少再往上调。
填超过本地宽带上限永远达不到，只会白跑满 10 轮。

**5. 点「开始扫描」。** 结果里的 IP 点一下就复制，历史保留最近 10 条。

## 结果怎么读

**达标** — 正常显示 IP 和各项数据。实测带宽 ≥ 你填的期望值，直接用。

**有结果但没达标** — 显示 IP 并附说明，例如「已测试 300 个未达到 200 Mbps，
返回最佳结果 61 Mbps」。这个 IP 是**可用的**，只是没到你设的目标。

**没找到** — 会区分两种情况：「筛选条件下没有可用 IP」说明条件太严，
放宽地区或端口；「已测试 N 个（共 M 轮）未找到」说明轮次用完了，
再点一次扫描会从没测过的继续。

**已取消** — 明确显示「扫描已取消」，不会伪装成「未找到」。

## 常见问题

**提示「当前这批 endpoint 都存在 RTT 丢包」？**

正常。节点会失效，列表里总有一部分是死的，程序会自动换下一批继续。

**扫描很慢？**

主要看期望带宽填多少。填得越高越难达标，就要试越多轮。上限 10 轮，
最坏情况也会结束。筛选范围太窄也会变慢。

**能和「官方优选」同时装吗？**

可以。两个是独立项目，包名不同（`com.cf.ip` / `com.gf.youxuan`），互不影响。
数据源和能力也不同：反代优选用已验证的节点列表、支持地区筛选；
[官方优选](https://github.com/liyanan2016-stack/guanfang-youxuan)从 CF 官方子网随机拼 IP、没有地区筛选。

**提示「仅供中国大陆网络环境使用」？**

关掉代理或 VPN 再重试。这个检查看的是你的网络出口位置，
开着代理时出口在境外，就会被拦下。

注意 v1.8 起检查在**每次扫描和更新数据前**都会做一遍，不是只在启动时查。
启动后再开代理同样会被拦。

**提示「无法确认当前网络环境」？**

这跟上一条不是一回事——它说的是检查本身没能完成（网络不通、请求被拦截、超时），
不是判定你在境外。确认能正常访问 cloudflare.com 之后点「重新检查网络」重试。

v1.8 起这种情况会拒绝而不是放行。原因很直接：如果检查失败就放行，
那断网、拦掉 cloudflare 域名本身就成了绕过限制的办法。

**为什么突然扫不了、提示拿不到数据？**

数据源是由维护者控制的。服务停止时所有客户端都会取不到数据，这是设计如此。

**Windows 提示不安全？**

没有买代码签名证书，SmartScreen 会拦一下，选「更多信息 → 仍要运行」。

不一致说明被重新打包过。各文件的 sha256 见 Release 说明。
